# Estimation-of-epidemiological-parameters

## Sitio de la tesis

La rama `Tesis` incluye un sitio estático en `docs/` para publicar la tesis
con GitHub Pages. Para activarlo en el repositorio, ve a **Settings >
Pages**, selecciona **Deploy from a branch**, elige la rama `Tesis` y la
carpeta `/docs`, y guarda los cambios.

El PDF publicado se encuentra en
[`docs/tesis.pdf`](docs/tesis.pdf); la página principal es
[`docs/index.html`](docs/index.html).
